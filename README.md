## Install or update

1. **[Download Setup.exe](https://github.com/jongbhak-collab/BioPager/releases/download/v1.1.1/BioPager-Setup-1.1.1.exe).**
2. Open it and follow the short setup guide.
3. Start BioPager from the Start menu.

Setup chooses the usual per-user application folder automatically. To update, run the newer installer; your settings are retained. There is no need to uninstall first.

## Use BioPager

- **Click a desktop tile** to switch desktops.
- **Double-click an app preview** to focus it.
- **Drag an app preview** onto another desktop to move that window.
- **Right-click BioPager** for layout, preview, app-logo and desktop options.

Eligible new profiles start with **seven desktops total**. Existing profiles keep their desktops and settings. Help and an offline Quick Start guide are included.
