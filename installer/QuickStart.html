BIOPAGER · WINDOWS DESKTOP PAGER

Your desktops, at a glance.

BioPager shows your application windows as small previews. Open it from the Windows Start menu by searching for BioPager.

Everyday controls

Switch desktopsClick a desktop tile.
Focus an appDouble-click its preview.
Move an appDrag its preview onto another desktop tile. Press Esc to cancel.
Open settingsRight-click the pager or its notification-area (tray) icon.
Move the pagerDrag the grip on the left. Docking and taskbar integration can restrict its position.
Recover a hidden pagerDouble-click the tray icon to return to a floating pager. Windows may place that icon under the tray's hidden-icons arrow.

Choose the view you prefer

Arrange app previews in a grid (show every app) keeps previews separate. Preserve desktop positions and window overlap shows their actual positions and stacking order. Fully covered apps can be reached by switching back to the grid. Minimized windows have a separate strip in spatial view.

Show app logo badges on previews identifies white or similar-looking windows. Under App logo badge size, choose 15%, 20%, 30%, or 50%. Use Larger tiles to make content easier to recognize.

Install, update, and uninstall

Setup normally installs to %LOCALAPPDATA%\Programs\BioPager, for your Windows account. Your preferences remain in %LOCALAPPDATA%\BioPager.

To update, run a newer BioPager-Setup-…exe. Setup closes the existing pager gracefully, replaces its installed program files, and keeps your settings and shortcut choices. There is no need to uninstall first. An older installer cannot overwrite a newer installed version.

Start BioPager when I sign in to Windows is optional and initially off. Run Setup again to enable or disable this option. Setup updates its own startup entry to the installed executable. Manually created startup shortcuts to an old portable copy are not removed; remove those separately to avoid launching that old copy.

Use Windows Settings → Apps → Installed apps → BioPager → Uninstall to remove the installed application and its managed shortcuts. Your preferences are retained. Old ZIP files and portable copies elsewhere are not deleted.

What “automatic upgrade” means: running a newer installer replaces the managed installation automatically. BioPager does not download new versions in the background. Setup is an offline, self-contained executable.

Preview limits and privacy

Browser windows show their active page, not every background tab. Minimized or inactive windows may show their last available view. Protected content may use an icon or label instead. Preview samples remain in memory and are not uploaded.

Other apps is a fallback group for genuine application windows whose desktop Windows cannot identify. The Windows input-helper filtering fix is included. Copy window diagnostics helps diagnose remaining cases; the report can contain private window titles, so review it before sharing.

Silent installation

For unattended installation without starting the app:

BioPager-Setup-1.1.0.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART

Add /LAUNCH to start BioPager afterward. Add /TASKS="startup,desktopicon" to opt into sign-in startup and a desktop shortcut. Normal interactive setup offers the same choices.
